# Rift Build Lab
Browser application for a League player exploring damage tradeoffs and unusual kit-based builds. Formula snapshot: 26.20 / 16.20.1. All 173 champions and AI-authored hypotheses are browsable. Partial numerical adapters cover Cassiopeia Q/E, Sett W, noncritical Blitzcrank E and Tahm Kench Q/W/enemy R. Unresolved crit/proc mechanics remain explicitly unverified. Hypotheses are not validated gameplay recommendations. Runtime AI generation is not available in this release.

User instructed us to proceed with the app. Inferred preferences: local-first, no accounts or API key, repeatable calculations, explicit coverage, keyboard-accessible desktop tool with mobile support.

The user chose this existing ChatGPT conversation as the build authoring workflow. The app prepares a local request, and the assistant writes complete proposals into the workspace inbox when asked here. The app loads the proposals for calculation and manual game tests, retaining observations for the next revision. It cannot independently invoke or message this conversation. The first inbox contains three Cassiopeia and three Sett experiments.

The published GitHub Pages app refreshes OP.GG and Lolalytics references daily. Provider freshness, formula snapshots and authored hypotheses have separate provenance. Observed provider cores can be loaded or pinned as baselines, retaining role, patch and sample; relative modeled comparisons require equal item counts and both setups within shared constraints. Baseline cores are not expanded into invented full builds. Valid working drafts restore after refresh; recorded tests support repeated measurements, a manual baseline and explicit ability/form/sequence conditions.


**Meta & teams** provides a current-source six-item recommendation for every champion in its configured provider role. Individual late-slot observations and explicit kit completions remain distinct from observed cores; joint six-item performance is not inferred. Local composition rules use four allies, five enemies and confirmed threat flags to explain optional-item/defensive-boot swaps while retaining source cores and their completions. Team drafts persist per champion; test proposals carry composition and source notes into manual testing. Daily publication validates full-roster completion after refreshing providers.
