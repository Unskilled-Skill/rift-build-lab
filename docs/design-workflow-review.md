# Design and workflow review — 2026-10-12

User direction: visual polish and workflow usability matter equally. Preserve the dark League research-tool identity and make choosing, testing and revising builds straightforward.

| Before | After | Why |
| --- | --- | --- |
| Request form dominates the build collection | Compact library with optional collapsed request | Show actionable proposals first |
| Dense prose and tiny item labels | Short question, readable items, keystone/cost; full details expandable | Compare routes without losing evidence |
| Manual champions cannot edit a loaded proposal | Setup, items and runes editable for all champions | Record the actual experiment |
| Feedback disappears across sections | Per-build session drafts and active-build continuation | Keep work while checking kit/items |
| Lower slot cap hides equipped items | All equipped items remain visible and removable | Make invalid configurations repairable |
| Exporting every result obscures the current build | Copy exact latest result, export current build, undo immediate save | Share a concrete revision request |
| Mobile header icons have unclear names | Explicit accessible labels, skip link and bench heading focus | Support keyboard and smaller screens |

Design references applied: Impeccable Operate/craft floor, Emil design engineering, Minimal readability, Design Taste audit principles, Web Interface Guidelines, and Animate/Review Animations/Improve Animations for restrained feedback. Motion audit found frequent laboratory actions should be immediate; only pointer color feedback remains, with reduced-motion support.

Validation: independent source review found no material regression. Browser checks cover manual setup/runes, overflow, validation focus, draft navigation, active continuation, save/copy/undo, and mobile overflow/accessibility. Interface smoke results are undone and are not represented as in-game measurements. Numerical coverage remains Cassiopeia Q/E and Sett W. No live AI generation was added.

Mechanical detector: first pass reported one legacy card accent declaration, removed; champion-row content visibility was also removed after a browser selection layout shift. Final confirmation reported zero findings. All 36 tests and the production build passed; no console errors or horizontal mobile overflow were observed.
