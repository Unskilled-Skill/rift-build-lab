# Rift Build Lab Implementation Plan
> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver a local browser app for current-patch champion research and reproducible Cassiopeia/Sett build comparisons.
**Architecture:** React TypeScript UI, compact generated source bundle, lazy champion formula details, pure numerical engine, cancellable Web Worker search, browser persistence.
**Tech Stack:** React, Vite, TypeScript, Vitest, Playwright.
**Spec:** ../specs/2026-10-10-build-lab-design.md

## Global Constraints
All 173 champions, 870 source item entries and 69 runes/shards remain browsable. Numerical coverage is limited and explicitly stated. Do not certify live-game optimality. No external publication or runtime AI API. Enemy and stack conditions are explicit. Reject invalid imports. Avoid granting omitted item/rune effects zero damage while calling the build fully evaluated.
